# Changelog

All notable changes to Dark Souls 2 Ultimate Cheat Engine Table (frullo edition).
Download: https://www.nexusmods.com/darksouls2/mods/1830

## 2.2.1
- Fix: on some setups ItemGib did not work ("attempt to perform arithmetic on a nil value"): the table now reads the game data even when a param has an unusual name, and shows a clear message if something is missing

## 2.2
- HOME: new STATS page (name, level, souls, Soul Memory, deaths, hollowing, covenant, journey, last bonfire), with the New Game+ cycle and the bonfire intensity you can change
- World & Progression: New Game+ Cycle and Bonfire Intensity (the area you are in) in the table too
- HOME: search box in MAIN FEATURES and CHEATS
- Character Editor: hollowing level, Become Human (like a Human Effigy) and Become Hollow
- Item Discovery Boost: enemies drop more items (x2, x5, x10)

## 2.0
- HOME ^-^ (was the Table Info): one window with the HOME, MAIN FEATURES, CHEATS, BACKUP, SETTINGS and CREDITS pages; turn options and cheats on and off from there
- SETTINGS page: update check, compact view and your hotkeys
- Keybinds: change the key of every function, with Ctrl / Shift / Alt (SETTINGS > Change keys)
- New default keys: F6 Unlimited Magic, F7 Unlimited Estus, F8 No Fall Damage
- Quick Save Position (F3) and Quick Return to Position (F4)
- Bonfire Warp: favorite bonfires and recent warps
- Character Editor: Soul Level follows the attributes (can be turned off)
- [ Quick Access ]: shortcuts to every window, now also Boss Teleport and Positions
- Cheats split into Survival, Movement, Enemies and Equipment
- New cheat: Player Speed (only your character faster or slower, x0.5 - x3)
- The classic entries the windows use (Bonfire Warp classic, boss teleport list, Save / Restore Position, covenant values, More Character Data) are in Advanced > Classic entries
- "Reallocate Stats" is now "Respec Menu (Reallocate Stats)"
- Update check also works after opening another version of the table in the same Cheat Engine session
