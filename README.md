# Dark Souls 2 Ultimate Cheat Engine Table (frullo edition)

A Cheat Engine table for **Dark Souls II: Scholar of the First Sin** that puts everything at hand, in one place, easy to use for anyone.

## ⬇️ Download

**[Dark Souls 2 Ultimate Cheat Engine Table on Nexus Mods](https://www.nexusmods.com/darksouls2/mods/1830)**

The table is downloaded from Nexus. This repository only holds the [changelog](CHANGELOG.md) and the `version.txt` file the table reads to tell you when a new version is out.

## ✨ Main features

- **HOME ^-^**: one window with every feature, cheat, backup and setting, plus your stats
- **Backup Manager**: back up and restore your saves (normal `.sl2` and Seamless Co-op `.co2`) without losing the current one
- **ItemGib**: spawn any item with quantity, upgrade level and infusion; favorites, recent items, kits you can share as text, DROP on the ground
- **Add Souls**: current souls, Soul Memory, +10k / +100k / +1M
- **Character Editor**: attributes, level up / respec / rename menus, Repair All Gear, weapon level and infusion, armor level, Estus Flask, Soul Memory, Become Human / Hollow, Undo
- **Covenants**: join, discover and rank up any covenant, or max them all in one click
- **Bonfire Warp**: every bonfire by area, favorites and recent warps, Unlock All Bonfires
- **Boss Teleport**: every boss by area, from anywhere (it warps to the area first)
- **Positions**: save your position with a name and go back there; Quick Save (F3) and Quick Return (F4)
- **New Game+ and Bonfire Intensity**: change your journey (NG ... NG+7) and the intensity of the area you are in
- **NPCs & Shops**: vendors, blacksmith and NPC menus from anywhere
- **Keybinds**: change the key of every function
- **English / Italian**: every window in both languages, with the official Italian names of items, bonfires and bosses
- **Cheats**: Noclip, Game Speed, Player Speed, Item Discovery Boost, unlimited stamina / magic / Estus, no fall damage, unlimited iFrames and more

## 📋 Requirements

- Dark Souls II: **Scholar of the First Sin**, Steam version **1.03** (the original DS2 is not supported)
- [Cheat Engine](https://www.cheatengine.org/) **7.4 or newer**

## 🛠️ How to use it

1. Start the game and load your character.
2. Open the table in Cheat Engine and attach it to `DarkSoulsII.exe`.
3. Tick the main entry at the top (`Open - DS2 SotFS Ultimate`).
4. Tick **HOME ^-^** to open the main window: from there you find everything.

**Make a backup of your save first** (HOME > BACKUP).

You can change them in HOME > SETTINGS > Change keys.

## ⚠️ Notes

- **Use it offline.** Cheats and changes to souls, items or Soul Memory can get you banned online.
- **Seamless Co-op**: weapons, armor and rings can be passed to friends with DROP, but other items (Estus Flask Shards, spells, many consumables) turn into Rubbish on your friend's side. This is done by the Seamless Co-op mod, not by the table: your friend can spawn those items with the table themselves.
